Reagera examples

Rust, compiled to WebAssembly. The event log is the state: ConTime keeps the history, minbin encodes the bytes.

  • React and Reagera, side by side: the same todo app twice, with what each framework keeps shown under it. Start here.
  • Todo: the classic app, with the devtools panel and the session kept in the URL.
  • Latency lab: two clients with delayed delivery. Compare individual and batch receipt of 1,000 late records, then restore the same history from minbin bytes.
  • Checkout: a slow, unreliable payment gateway. The charge is a request, the answer is a record, a replay charges nobody.
