the code

fn resolve(state, request, outcome, ctx) {
    let used = request.query == state.query;
    if used { state.results = outcome.names; }
}

The check is code that you write. Remove it, and Reagera has the same bug. The framework gives the check what it needs: the request and the state of this moment.
